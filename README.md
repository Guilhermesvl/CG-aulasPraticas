# 💻 Aulas Práticas – Computação Gráfica

Este repositório contém as **aulas práticas** desenvolvidas durante a disciplina de **Computação Gráfica**.
Cada diretório representa um exercício resolvido em sala.

---

## ⚙️ Como Executar

A compilação e execução dos códigos podem ser feitas diretamente pelo **Makefile** presente em cada diretório.

No terminal, dentro da pasta do exercício, digite o seguinte comando para compilar e executar de uma só vez:

```bash
make && ./main
